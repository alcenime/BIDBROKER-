Learn how BIDBROKER auctions, token mechanics, and NFT mining work.

Documentation is evolving. Unconfirmed protocol parameters will be announced when finalized.

Introduction

BIDBROKER is an NFT auction and ETH mining ecosystem on Robinhood Chain, powered by BID tokens.

Miner NFTs are acquired through auctions rather than a conventional fixed-price mint. Owners can then use eligible Miner NFTs to take part in ETH mining.

How It Works

  1. Users bid on Miner NFTs using BID tokens.
  2. The highest bidder wins when the auction ends.
  3. Outbid users can claim refundable balances.
  4. Owners can use eligible Miner NFTs for ETH mining.
  5. Mining rewards depend on the available ETH reward funds and protocol rules.

Quick Start

The intended user journey is:

  1. Connect a compatible wallet when wallet integration is available.
  2. Obtain BID tokens.
  3. Participate in an NFT auction.
  4. Claim a refund if you are outbid.
  5. Activate mining after obtaining a Miner NFT.
Wallet integration and other functionality are subject to implementation and may not be available yet.

NFT Auctions

  • Maximum NFT collection supply: 5,555.
  • Only one NFT auction runs at a time.
  • Each new auction begins with a 30-minute countdown.
  • Once the first valid bid is placed, the countdown changes to 2 minutes.
  • Each subsequent valid highest bid resets the countdown to 2 minutes.
  • When the countdown reaches zero without another valid bid, the highest bidder wins.
  • The next NFT auction begins with a fresh 30-minute countdown.

Countdown timeline

  1. 0130:00Auction opens with no bids.
  2. 022:00First valid bid switches the countdown.
  3. 03Reset to 2:00Every new valid highest bid resets it.
  4. 040:00No new valid bid. Highest bidder wins.
  5. 0530:00Next auction starts fresh.

Refunds

  • The current highest bidder's bid remains locked.
  • When another user outbids them, their previous bid becomes refundable.
  • Users must claim their refundable balance before reusing those funds for another bid.
  • Refundable balances remain separate from tokens designated for burning.

Token Burn

BID is used for bidding, and the protocol includes a token-burning mechanism. The burn rules below are described only as far as they are confirmed.

TermMeaning
Bid principalThe BID amount a user bids. It is not assumed to be burned.
Separate bid feeAny fee charged on top of a bid, if one applies. To be announced
Refundable balanceA previous bid that has been outbid. Owed to the user and never burned.
Tokens designated for burningBID tokens defined by the protocol as burned. Burn amounts and rules: To be announced

These values are distinct and should not be assumed to be equal.

ETH Mining

Miner NFTs can be used to participate in ETH mining. Mining rewards are paid in ETH and funded from a portion of the ETH fees the project receives from token launches.

  • There is no epoch-based reward schedule.
  • No fixed ETH reward per hour is promised.
  • Returns are not guaranteed.

Security & Risks

Participation involves risk. Only use funds you can afford to lose.
  • Smart contract vulnerabilities. Contracts may contain bugs or be exploited.
  • Price and liquidity volatility. Token and NFT prices can fall, and liquidity may be limited.
  • Reward availability. ETH rewards may be reduced or unavailable depending on the reward funds.
  • Transaction costs. Network fees apply, and transactions can fail.
  • Verify addresses. Always check official contract addresses before interacting.

No audit or security guarantee is claimed unless verified information is published.
